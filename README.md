## How I build

- App Router + Server Components で CMS／ページを組み立て、API Routes でフォームやプロジェクト取得を担う
- 体験はリッチに、失敗時はフォールバック（GPU、APIリトライ、ルールベース代替）を残す
- lint / format / test を CI でゲートし、PR では目的・スクショ・自己レビューを残す
- セキュリティパッチや描画の軽量化など、公開後も継続的に直す
